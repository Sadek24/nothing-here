# For Lina 💗 — Romantic Apology Website

A simple static website made with HTML, CSS, and JavaScript. The page includes a heartfelt apology in Algerian Darija, French, and English, animated hearts, and symbolic Python/C++/Java code snippets.

## Run it in VS Code

1. Extract `lina_apology_website.zip` to a folder.
2. Open VS Code.
3. Choose **File → Open Folder...** and select the extracted `lina_apology_website` folder.
4. In the Explorer, open `index.html`.
5. Easiest: install the **Live Server** extension by Ritwick Dey, then right-click `index.html` and choose **Open with Live Server**.
6. Or simply double-click `index.html` in File Explorer to open it in your browser.

No Node.js, Python, C++, or Java installation is needed to view the website. The code examples are displayed as messages; they are not executed by the website.

## Customize the message

Open `index.html` and edit the Darija, French, and English paragraphs. Keep the message honest and specific to what you want to say. The website cannot replace listening and showing care through actions.

## Files

- `index.html` — page content and messages
- `style.css` — pink romantic theme, responsive layout, animations
- `script.js` — floating hearts and interactive buttons

The optional Google Fonts import needs an internet connection; the site falls back to system fonts if unavailable.
